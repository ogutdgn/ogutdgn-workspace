## **Project Details**

The initial template only provided a static design built with HTML and CSS.
I enhanced this template by adding dynamic **Gallery** and **Blog** sections, enabling veterinary clinics to share updates, announcements, and visual content with their visitors.

To make the website fully manageable, I developed a dedicated **Admin Dashboard** for veterinary owners. Through this dashboard, admins can securely log in and perform full **CRUD operations** (Create, Read, Update, Delete) on:

- Website content and section titles
- Gallery images
- Blog posts

The frontend was developed using **HTML, CSS, and JavaScript**, focusing on clean structure and usability.

For the backend and content management system, I integrated **Sanity CMS** to provide a fast, secure, and scalable solution. Instead of building a custom backend and database from scratch, Sanity allowed efficient content management with minimal overhead, which is ideal for small-to-medium business websites and offers better security and maintainability.

This project is **not open source**, as it was developed as a **client-specific commercial product**. For demonstration purposes, the **frontend source code** is available on my GitHub to showcase my ability to customize templates, build admin-managed content systems, and deliver real-world client solutions.
